# 界面与操作指引

> 面向日常使用。文档按"你会看到的四块界面"组织：**顶部同步气泡**、**底部会话状态条**、
> **侧栏会话行标记**、**设置页**。术语见 [GLOSSARY](GLOSSARY.md)；状态机细节见
> [SYNC-STATE](../ui/SYNC-STATE.md)。

## 0. 四块界面

| 位置 | 名称 | 作用 | 何时出现 |
|---|---|---|---|
| 应用顶部 | 同步气泡 | 整轮同步的入口与进度 | 常驻（可收起成图标） |
| 窗口底部 | 会话状态条 | 当前会话的同步状态与单会话操作 | 常驻，跟随当前会话 |
| 侧栏会话行 | 行标记 | 该会话正在同步/等待/分叉 | 有活动时 |
| 设置页 | 会话云同步 | 服务端、凭据、上传范围、工作区映射 | 手动进入 |

## 1. 首次配置

从气泡底部「设置」进入，或从设置页找到「会话云同步」。

| 字段 | 说明 |
|---|---|
| 服务端地址 | `http://host:port`。**多设备写法必须一致**（不要混用 `localhost` / `127.0.0.1`、不要省略 `//`），默认盐由规范化后的地址派生（去尾斜杠、小写 scheme/host、去默认端口） |
| 设备名称 | 出现在设备台账与租约里，多设备时用来区分 |
| 同步口令 | 凭据，不写进配置文件。**所有设备必须相同** |
| 设备 token | 凭据，只用于服务端鉴权，不参与解密 |
| 上传范围 | 勾选要参与同步的根会话；子代理随根会话一起同步（可关闭「包含子代理」） |
| 自动绑定同名路径 | 远端工作区 key 与本机路径推导结果相同就自动绑定 |
| 自动同步 / 间隔 | 关闭后只在启动时推一次；手动同步随时可用 |

保存后插件会重新校验连接；配置不完整时气泡只显示引导，不产生同步任务。

## 2. 顶部同步气泡

### 常驻入口
左上角云朵图标是常驻入口，点它展开/收起。图标右下的小圆点表示整体状态。

### 标题与副标题

| 标题 | 含义 | 副标题示例 |
|---|---|---|
| 同步完成 | 没有待处理项 | `70/70 个会话 · 刚刚` / 尚未成功 |
| 正在同步 | 有传输在进行 | `上传中 · 3 个会话` |
| 等待处理 | 有会话在等外部条件 | `等待拉取 · 2 个会话` |
| 部分待处理 | 有会话被推迟 | `2 个会话等待拉取/关闭/cwd 处理` |
| 只读同步 | 全局写租约在别的设备 | `另一台设备持有全局同步锁；本机只拉取` |
| 需要处理 | 有会话历史分叉 | `1 个会话历史分叉，已阻止继续写入` |
| 同步失败 | 本轮有错误 | `有会话未完成，已暂停` |

### 进度带
气泡中间的进度带按会话分段：**左端是本机、右端是服务端**。上传向右填充，拉取向左填充；
只有真实进度会改变分段宽度，不做循环闪烁。

### 展开列表
展开后每个会话一行：

- **名称**：会话标题 · 短 id；
- **事件数**：`↑ 已完成/总数`（上传）或 `↓ 已完成/总数`（拉取）；
- **标签**：`待上传` `待拉取` `校验中` `上传中` `下载中` `完成` `等待` `分叉` `失败`。

列表**是实时增减的**：新任务进入时淡入，完成后先淡出再移除。

### 底部按钮

- **立即同步**：完整跑一轮——先逐会话校验（此时列表显示「校验中」），校验完的
  已对齐会话会被移除，然后才逐会话传输。正在同步时按钮禁用。
- **设置**：打开设置页。
- **回到当前同步**：当你手动滚动列表离开当前同步项时出现。

### 自动展开与收回

| 场景 | 行为 |
|---|---|
| 整轮同步开始 | 自动展开，结束后保留结果列表 |
| 单会话推送（底栏触发） | 自动展开，空闲 3 秒后自动收回 |
| 用户点开/钉住 | 不自动收回，失焦 5 秒后视情况收起 |
| 全局写租约被其他设备持有 | 不自动展开，只更新圆点与副标题 |

### 列表为空时
所有会话都对齐后列表会变空，此时显示一句空闲文案（每次清空换一句）。
这是唯一会看到它的场景：点「立即同步」→ 校验全部通过 → 条目全被移除。

## 3. 底部会话状态条

贴在窗口最底部，**跟随当前打开的会话**；切换会话会立即换到新会话的状态。

### 元素

```
● 已同步  a1b2c3d4…  ▬▬▬▬▬▬▬▬▬  本地 5314   -46  [↑ 推送]  [上传本会话 ●─]  [详情]  收起
                       ▬▬▬▬▬▬▬▬▬  远端 5360
```

| 元素 | 含义 |
|---|---|
| 状态点 | 颜色见下表；同步进行中会呼吸闪烁 |
| 短 id | 当前会话 id 前 8 位 |
| 双细条 | 上行=本地、下行=远端；绿色是共同前缀，尾段=差值（本地领先橙、远端领先蓝） |
| 本地 / 远端 | 两侧的末事件序号；会话正在生成时本地数字实时增长 |
| 差值 chip | `+N`（本地领先，待上传）/ `-N`（远端领先）/ `一致` |
| ↑ 推送 | 只同步这一个会话 |
| 上传本会话 | 是否把该会话加入上传范围 |
| 详情 | 末序号、远端 head 哈希、格式版本、租约状态、阻塞原因 |
| 收起 | 收成 18px 细条，状态记忆在本地 |

### 状态点颜色

| 颜色 | 含义 |
|---|---|
| 绿 | 本地与远端一致 |
| 黄 | 本地领先（有事件待上传） |
| 蓝 | 远端领先（需要拉取） |
| 红 | 历史分叉，已阻止写入 |
| 呼吸动画 | 该会话正在同步（不改变颜色所表达的对齐状态） |

### ↑ 推送

- 只上传本会话，不触发整轮校验；
- 会话正在生成（尾未闭合）时会先弹确认：**只推到安全边界**，已闭合部分才会传；
- 同步任务进行中、历史分叉、或全局租约被其他设备持有时，按钮禁用（分别是「同步中…」「历史分叉」「等待全局同步租约」）。

### 上传本会话（开关）

等价于设置页上传列表里的那一项，改的是同一份 `syncSessionIds`。

- **打开**：立即写入并生效；若该会话所在工作区还没绑定远端工作区，会弹窗让你
  **选择已有远端工作区**，或**按本地路径新建**一个（远端没有可用工作区时会提示"会新建"）；
- **关闭**：从上传范围移除，**只停上传**——本机仍会跟随远端更新（拉取范围由绑定工作区决定）。
  这一项为"废弃会话不再上传"设计，不是"彻底不同步"。

### 详情

```
会话同步
会话    a1b2c3d4
本地    5314
远端    5360 · 7a91c1ee
差异    远端领先 46
格式    v4
租约    已持有
阻塞    （仅分叉时出现）
```

### 收起
点最右「收起」变 18px 细条：`▸ ● 已同步 a1b2c3d4…`。展开状态与折叠状态都记在浏览器本地。

## 4. 侧栏会话行标记

会话行前会出现一个小标记，鼠标悬停有说明：

| 标记 | 含义 |
|---|---|
| `↑` | 正在上传该会话 |
| `↓` | 正在下载该会话 |
| `!` | 历史分叉，已阻止；或需要你处理 |
| 闪烁点 | 正在校验 / 等待条件 |

同步完成且无异常时标记消失，不占用行空间。

## 5. 常见状态与处理

| 现象 | 含义 | 处理 |
|---|---|---|
| 气泡显示「只读同步」 | 全局单写者租约在另一台设备 | 等它结束；本机会自动重试 |
| 底栏蓝点 `-N` | 远端领先 | 本机会话已打开时写句柄被官方占用，**本机无法拉取**；关闭该会话后重启再同步 |
| 红点「历史分叉」 | 本地与远端历史已经分叉 | 行内选择忽略/强制/恢复，或生成"远端覆盖本地"脚本后手动处理 |
| 拉取报「封帧的 keyId 与当前密钥不符」 | 各设备口令、盐或服务端地址写法不一致 | 统一三者后重试 |
| 收到会话提示 cwd 在工作区外 | 会话的 cwd 不属于任何已绑定工作区 | 按提示选择修正或直接挂载 |
| 气泡副标题「N 个会话等待拉取/关闭/cwd 处理」 | 有会话在等会话关闭或 cwd 决策 | 关闭对应会话，或处理 cwd 提示 |
| 插件提示版本不兼容 | 插件与 DSH/服务端版本不匹配 | 对照 [README](../../README.md) 的支持版本升级 |

## 6. 多设备

- 所有设备使用**同一同步口令**；`serverUrl` 写法一致（默认盐由它派生）；
- 同一时间只允许一台设备**写**（全局单写者租约），其余设备只拉取；
- 设备台账、workspace/profile 与一次性工作区映射见 [VAULT](../sync/VAULT.md)；
- 多设备时用「设备名称」区分是谁在写。

## 7. 键盘与无障碍

- 气泡展开/收起与列表按钮可用 Tab 聚焦，`Esc` 收起；
- 底栏开关是按钮，支持键盘触发，带 `aria` 状态；
- 系统开启"减少动态效果"时，动画时长压到接近 0，但状态信息不丢失。

## 8. 已知限制（0.1.4）

- 界面文案目前只有中文，未做多语言；
- "远端领先"在会话已打开时无法在本机解决（写句柄被官方占用），只能等关闭会话后拉取；
- 「上传本会话」只控制上传，不控制拉取（见上文）；
- 单会话推送不记录"本轮结果"，完成后不在气泡里保留面板；
- 附件同步（0.1.5 起）需要服务端 0.1.5+（按 `attachment-index` capability 门控），旧服务端只同步事件；
- 单个附件上限 32 MiB：超限的附件不上传，另一端修复时报「附件过大」；拉取时附件没补齐会在 apply 前阻塞，不会写出半成品会话。
