# 前端动效约定

> 适用于 `dsh-session-cloudsync` 的所有客户端页面（设置页、首启、同步气泡、会话行标记）。原型见 [dev/ui/index.html](../dev/ui/index.html)。

## 1. 只在状态变化时动

动画要解释“发生了什么”，不是装饰：

- 进入/退出：同步气泡从顶部滑入，完成后收回；
- 展开/收起：会话列表用高度过渡，箭头同步旋转；
- 进度：每段进度条只随真实进度变化，不做循环闪烁；
- 可收起浮层保留一个常驻入口（图标/按钮），入口本身承担展开/收起，并支持 Esc 收起；用户操作过后可设失焦计时（原型用 5s），焦点/指针回到浮层时取消，焦点在浮层内时不收回；
- 收起态与展开态尽量是**同一个元素**：用宽高/圆角/最大高度过渡让它长成卡片、再缩回图标，不要复制一个图标做交叉淡入；收起时内部文字/进度条要淡出或随卡片裁剪，不要用 `display:none` 瞬消；所有会改变内部元素位置的尺寸（header 高度、padding、图标尺寸）都要一起过渡，避免图标在展开瞬间下移；右侧元数据用 auto margin 固定到右边界，避免 morph 时先往左再往右；
- 常驻入口要放在页面视图之外（overlay 层），切换页面不重建 DOM，否则 `图标 → 气泡` 仍会被拆成两段；
- 错误：用颜色和一条错误说明出现，不反复抖动或脉冲；
- 不添加常驻的呼吸、漂浮、无限旋转装饰动画。

## 2. 时长与缓动

| 场景 | 时长 | 缓动 |
|---|---|---|
| 按钮/开关/悬停 | 120–180ms | `ease-out` |
| 展开/收起列表 | 220–320ms | `cubic-bezier(.2, .8, .2, 1)` |
| 气泡滑入 | 320–420ms | `cubic-bezier(.16, 1, .3, 1)` |
| 气泡收回 | 240–300ms | `ease-in` / `cubic-bezier(.55, 0, .8, .35)` |
| 向导步骤切换 | 220–300ms | `cubic-bezier(.2, .8, .2, 1)` |
| 进度填充 | 150–250ms | `linear`（不要用回弹） |

同一页面里的时长保持同一量级，不要一个 80ms、一个 800ms。

## 3. 只动合成友好的属性

优先 `transform`、`opacity`、`grid-template-rows`；避免对 `width`、`height`、`top`、`left`、`margin` 做连续过渡。列表展开用 `grid-template-rows: 0fr → 1fr`，内容内部再做 `opacity` + `translateY(-4px)`，比直接动 `max-height` 稳定。

## 4. 可交互与可访问

- 动画容器要裁掉横向溢出（例如 `overflow-x: hidden`），否则步骤滑动会在底部闪出一条横向滚动条；
- 收起的内容加 `inert`，避免 Tab 焦点进入不可见区域；
- 展开/收起按钮维护 `aria-expanded` 与 `aria-controls`；
- 动画不能抢焦点、不能让文字在动画中不可读；
- 必须支持 `prefers-reduced-motion: reduce`：把动画时长压到接近 0，保留最终状态；
- 窄屏下同一套动效不改变控件位置关系。

## 5. 实现检查

- 交互控件不要因为状态变化重建 DOM：开关、折叠、进度都只更新状态类或属性，否则 CSS 过渡不会触发；
- 动画是否由状态变化触发，而不是页面加载就自动播放；
- 展开中途再次点击能否平滑反向，不跳变；
- 进度更新是否只改宽度，不重建整块 DOM；
- 关闭动画后，所有信息是否仍然完整可见；
- 减少动态效果时，是否没有残留的延迟或空白占位。
